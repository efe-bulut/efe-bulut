## About Me
I love building software, and I study and practice it every day. Outside of class I build my own projects and try to learn something new from each one. I've also started freelance web work, building a website for a marina client in Northern Cyprus.

Right now I'm practicing algorithms and data structures in C++ and Python.

## Projects

**Kodemanas**: real-time voice, text and DM platform for a friend group, used with real users.
Built with WebRTC and Supabase. Handled mute-state race conditions and ICE candidate latency. <br>
**link:** https://kodemanas.vercel.app/

**Petrito**: Windows desktop pixel-art cat companion with Pomodoro timer, to-do list and optional AI chat (bring your own key).
Built with Tauri. In development, Microsoft Store release planned.

**DeltaMarina**: marina and boat listing website built for a client. Next.js, Supabase, multilingual.
Product direction, design, content, i18n and Supabase integration by me, built with AI-assisted development. <br>
**demo:** https://delta-marina-chi.vercel.app/tr

**Restaurant Reservation & Ordering System**: university team project (3 people). Customers reserve tables and order food online, and an admin panel manages the menu and reservations. I designed the database (6 tables) and built the login page and login flow. Built with HTML, CSS, JavaScript, PHP and MySQL, running on XAMPP. <br>
**link:** https://github.com/efe-bulut/Restaurant-Online-Reservation-and-Ordering-System

**First game**: released a Unity game on itch.io at age 14. <br>
**link:** https://sekio.itch.io/newcells
